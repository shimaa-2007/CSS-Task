# 🎓 Eduleb - Educational Landing Page & Contact Task

A clean, responsive, and modern multi-page web design for an e-learning platform using **HTML5** and **Pure CSS3**. Created as a practical CSS training task/template.

---

## 🚀 Key Features

- **Home Page (`index.html`):**
  - **Hero Section:** Interactive search bar and student stats badges.
  - **Learning Journey:** Clean step-by-step educational roadmap.
  - **Popular Categories & Courses:** Custom grid-based layout for courses with hover effects and badges.
  - **Instructors & Testimonials:** Section showcasing team members and student reviews.
  - **Brand Marquee & Video Player:** Smooth CSS animation slider for brand partners and embedded media player.
- **Contact Page (`contact.html`):**
  - Styled contact form with focused input interactions.
  - Embedded Google Maps location frame.

---

## 🛠️ Built With

- **HTML5:** Semantic structural layout.
- **CSS3:** Custom styles, Flexbox, transitions, and keyframe animations.
- **Font Awesome 6:** Modern vector icons.
- **Google Fonts:** Montserrat typography.
